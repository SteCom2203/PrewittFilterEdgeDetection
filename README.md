# PrewittFilterEdgeDetection
--> **Quick overview**

This repository hosts a school project on picture edge dectection. Using Prewitt Filter, pictures are returned in grayscale, with the edges being the only parts visible.

--> **Technical overview**

This repository uses:
  - C++

Following is the project structure: 
  || Users enter upload their pictures (as matrixes or CSV files only) -> The scripts apply Prewitt filter on the matrix (convolution) -> A new array, with only the edges is returned (matrix) ||
